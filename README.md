# MeshDNS

[![Build](https://img.shields.io/badge/build-under_construction-lightgrey)](#) [![Status](https://img.shields.io/badge/status-MVP_scaffold-blue)](#)

MeshDNS is the service registry for AI agents: MCP servers register capabilities and health endpoints, and agents call `resolve("capability")` to get the best available server. Under construction.
